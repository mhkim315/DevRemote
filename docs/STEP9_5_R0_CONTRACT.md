### 1.1 Gradle version decision (R0 freezes this choice)

**Constraint:** AGP 8.12.0 requires Gradle 8.13 minimum.
The current wrapper is Gradle 9.3.1.

**Options evaluated:**

| Option | Compatibility | Risk |
| --- | --- | --- |
| A: Pin Gradle 8.13 (minimum for AGP 8.12.0) | Meets AGP requirement; still avoids 9.x + foojay-resolver incompatibility | Narrow — requires exact 8.13; AGP upgrade may force bump |
| B: Fix foojay-resolver for Gradle 9.3.1 | Allows keeping 9.3.1 | Unknown RN 0.85.3 + Gradle 9.x surface beyond resolver |

**Decision: Option A — Gradle 8.13.** It satisfies the AGP 8.12.0 minimum,
avoids the foojay-resolver incompatibility entirely, and stays on a
well-tested AGP/Gradle pair.

### 1.2 foojay-resolver incompatibility

**Observed:** Gradle 9.3.1 + `org.gradle.toolchains.foojay-resolver-convention`
0.5.0 does not recognize `IBM_SEMERU`. Clean build fails.

**R0 resolution (R1 implements):** If Gradle 8.13 + foojay 0.5.0 builds
successfully, the resolver stays. If the build still fails, the fix must
be source-controlled (config plugin or `app.json` setting). Direct
`node_modules` editing (e.g., patching
`@react-native/gradle-plugin/settings.gradle.kts`) is prohibited.

### 1.3 Gradle sources classification

## 2. Clean native-generation ownership

### 2.1 Problem

`npx expo prebuild --platform android --no-install` clears and regenerates
`mobile/android/`. The regenerated `AndroidManifest.xml` removes
`android:usesCleartextTraffic="true"` from the `<application>` element. This
setting is required by the bounded Pairing V1 LAN HTTP `/pair` transport.

### 2.2 Classification

Expo prebuild does not preserve custom manifest attributes not expressed
through `app.json`. The `usesCleartextTraffic` setting is manually added to
the tracked manifest but is not declared in Expo's config schema.

### 2.3 R1 resolution

Must provide ONE source-controlled mechanism:

- **(Preferred)** A narrow Expo config plugin in `mobile/plugins/` that
  injects the attribute into the generated manifest.
- **(Prohibited)** Manual manifest restoration, copying a prior generated
  Android tree, or committing the entire `mobile/android/` directory.

### 2.4 Required generated-manifest assertions

After clean prebuild, the following must be preserved:

| Setting | Required Value | Authority |
| --- | --- | --- |
| `android:usesCleartextTraffic` | `true` | Pairing V1 LAN transport |
| `android:allowBackup` | `true` | Keystore backup |
| `android:fullBackupContent` | `@xml/secure_store_backup_rules` | Keystore |
| `android:dataExtractionRules` | `@xml/secure_store_data_extraction_rules` | Keystore |
| Package name | `com.pokit.mobile` | Application identity |
| Deep link scheme | `pokit` | Activity routing |
| Camera permission | `android.permission.CAMERA` | QR pairing |
| Notifications | Firebase/messaging | N1 push |

## 4. Fail-closed clean-clone build state machine

### 4.1 Entry point

```text
BUILD_ENTRYPOINT=scripts/build-artifacts.sh
EXPECTED_SOURCE_SHA=<production candidate>
```

### 4.2 State machine

```
[Clean Clone] → [Validate Toolchain] → [Install Dependencies]
  → [Prebuild Android] → [Validate Generated Manifest]
  → [Build Daemon] → [Validate Daemon Identity]
  → [Build APK] → [Validate APK Identity]
  → [Freeze Artifacts] → [Done]
```

Each stage fails closed. Partial artifacts must not be produced.

### 4.3 Daemon build

- `-trimpath` required
- `vcs.revision` must equal `EXPECTED_SOURCE_SHA`
- `vcs.modified` must be `false`
- Build timestamp = deterministic source commit timestamp

### 4.4 Clean-clone requirement

Production artifact builds must use a **clean real clone**. The build
entrypoint validates:

```bash
test -d .git || { echo "FATAL: not a real clone"; exit 1; }
```

Linked worktrees (`.git` is a file reference) are not authorized for
production builds. The VCS metadata path depends on filesystem state
outside the worktree.

**Reclassification:** The observed worktree VCS failure is a
build-invocation/checkout problem, not a Go limitation. Go `-buildvcs=true`
(default) works from linked worktrees when the main repository is
accessible, but the dependency is fragile. Clean-clone eliminates the
ambiguity.

### 4.5 Daemon identity validation (R1)

```bash
DAEMON_VCS=$(go version -m pokit-daemon | grep 'vcs.revision=')
DAEMON_DIRTY=$(go version -m pokit-daemon | grep 'vcs.modified=true')
test -n "$DAEMON_VCS" || { echo "FATAL: missing vcs.revision"; exit 1; }
test -z "$DAEMON_DIRTY" || { echo "FATAL: vcs.modified=true"; exit 1; }
```

## 5. Formula/frozen-daemon identity policy

### 5.1 Policy

- The **frozen daemon** is the authoritative artifact. Built from a clean
  real clone with full VCS metadata.
- The **formula daemon** is a convenience path. Embeds source SHA via
  `-ldflags` (`cliGitSHA`). Missing Go VCS metadata is expected
  (tarball builds lack `.git`).
- Formula and frozen daemon are NOT required to be byte-identical.
- The formula pin must point to the exact production source candidate.

## 8. ACCEPT/REJECT gates

### ACCEPT

Independent reviewer confirms:

1. Supported toolchain tuple is documented and compatible (Gradle 8.13
   selected for AGP 8.12.0; foojay-resolver removed; JDK 21 Temurin)
2. Clean prebuild failure is reproducible from diagnostic SHA
3. Linked-worktree VCS issue reclassified as build-invocation; clean-clone
   policy is frozen

6. Formula identity policy distinguishes convenience from authority
7. Clean-clone state machine is complete with `.git` directory check
8. No implementation is started before R0 ACCEPT
9. Version pins specified but NOT created (R1 creates `.nvmrc` + `engines`)
10. Sections 1, 3.2, and 6 agree on toolchain tuple and allowed files
11. Package name is `com.pokit.mobile` throughout
12. Validators are concrete: Temurin/Adoptium for Java, `sdkmanager --list`
    for build-tools, exact Node 20.19.4

### REJECT

The contract is rejected if it:
- Relies on a developer-local generated directory
- Permits manual manifest restoration
- Uses mutable global packages without version pinning
- Proposes Gradle 9.3.1 without compatibility evidence
- Authorizes linked-worktree builds for production artifacts
- Creates source files before R0 ACCEPT (`.nvmrc`, `engines`)
- Uses wrong package name (`com.pokit.devremote`)
